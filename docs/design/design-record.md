# GIU 보드게임 대여 디자인 기록

기준일: 2026-09-07

## 대표 시안

- 이미지: `giu-boardgame-lending-primary-design.png`
- 적용 대상: 회원 대여 화면을 시작으로 내 페이지, 약속 화면, 관리자 화면 전체
- 핵심 목표: 원하는 게임을 빠르게 찾고 대여 가능 여부와 다음 행동을 즉시 이해하게 한다.

## 공통 구조

- 슬림한 좌측 사이드바를 주요 탐색 축으로 사용한다.
- 화면 상단에는 현재 페이지 제목, 계정 동작, 필요한 경우에만 개인 대여 현황을 둔다.
- 회원 대여 화면은 큰 검색바를 가장 강한 1차 동작으로 유지한다.
- 게임은 추천 묶음보다 전체 목록형 표를 기본으로 제공한다.
- 필터는 검색바 아래 한 줄에 배치하고 초기화 동작을 분리한다.
- 목록 행은 작은 게임 이미지, 핵심 조건, 상태, 명확한 1차 버튼 순으로 읽힌다.

## 시각 언어

- 배경: 따뜻한 아이보리 또는 오프화이트
- 주요색: 딥 포레스트 그린
- 보조색: 뮤트 세이지
- 본문색: 차콜
- 강조색: 승인 대기·경고처럼 주의가 필요한 상태에만 제한적으로 코랄 사용
- 반경: 8~12px
- 본문 크기: 14~16px
- 그림자: 거의 사용하지 않고 간격과 얇은 구분선으로 계층을 만든다.

## 확장 우선순위

1. 회원용 내 페이지: 현재 대여와 반납 행동을 먼저 보여준다.
2. 게임 약속 만들기: 폼과 게임 선택을 한 흐름으로 정리한다.
3. 관리자 승인 대기: 요청 사진, 사용자, 기한, 승인·거절 판단을 한 행에서 처리한다.
4. 나머지 관리자 페이지: 같은 사이드바, 필터, 표, 상태 배지, 폼 규칙을 재사용한다.

## 확장 시안

- 회원용 내 페이지: `giu-member-account-design.png`
  - 현재 대여와 반납 가능 상태를 최상단에 배치한다.
  - 월 대여 사용량 `2/5`를 항상 확인할 수 있게 한다.
  - 내 평점과 브릿지 기록은 탭으로 묶어 정보 밀도를 낮춘다.
- 게임 약속 만들기: `giu-meetup-create-design.png`
  - 기본 정보 → 게임 선택 → 확인의 3단계 흐름을 사용한다.
  - 필수 입력과 게임 선택을 한 카드 안에서 순서대로 처리한다.
- 관리자 승인 관리: `giu-admin-approval-design.png`
  - 대기 건수와 처리 현황을 상단 요약으로 제공한다.
  - 요청 목록과 선택된 신청 상세를 나란히 보여 승인 판단 이동을 줄인다.
  - 승인·거절은 행과 상세 패널 모두에서 실행할 수 있게 한다.

## 보존 원칙

- 기존 서버 동작과 데이터 구조는 변경하지 않고 시각 계층과 탐색 구조를 개선한다.
- 모바일에서는 사이드바를 접이식 탐색으로 전환하고 검색과 주요 행동을 우선한다.
- 카드 안의 카드, 거대한 지표 카드, 불필요한 장식 이미지는 피한다.

## 전체 제품 확장 적용

- 데스크톱 공통 사이드바는 176px로 통일하고 브랜드와 메뉴를 왼쪽 정렬한다.
- 모바일은 64px 상단바와 70px 하단 주요 탐색으로 전환한다.
- 로그인과 회원가입은 브랜드 스토리 영역과 행동 중심 폼 영역을 분리한다.
- 관리자 보조 탐색, 상태 배지, 표와 폼은 기존 서버 동작을 유지한 채 동일 토큰을 사용한다.
